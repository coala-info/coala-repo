## igua

### Original Help Text
```text
usage: igua [-h] [-V] [-j N] -i INPUT [-o OUTPUT] [-C COMPOSITIONS]
            [-F FEATURES] [-w WORKDIR] [--prefix PREFIX] [--no-clustering]
            [--clustering-method {complete,centroid,weighted,single,median,average,ward}]
            [--clustering-distance CLUSTERING_DISTANCE]
            [--precision {single,half,double}]

A method for content-agnostic high-throughput identification of Gene Cluster
Families (GCFs) from gene clusters of genomic and metagenomic origin.

optional arguments:
  -h, --help            Display this help message and exit.
  -V, --version         Display the program version and exit.
  -j N, --jobs N        The number of threads to use in parallel sections.

Input:
  Mandatory input files required by the pipeline.

  -i INPUT, --input INPUT
                        The GenBank files containing the clusters to process.

Output:
  Output files generated by the pipeline.

  -o OUTPUT, --output OUTPUT
                        The name of the ouput file to generate.
  -C COMPOSITIONS, --compositions COMPOSITIONS
                        A file where to write compositional data for GCF
                        representatives.
  -F FEATURES, --features FEATURES
                        A file where to write protein cluster representatives
                        in FASTA format.

Parameters:
  General purpose parameters.

  -w WORKDIR, --workdir WORKDIR
                        A folder to use for temporary data produced by
                        MMSeqs2.
  --prefix PREFIX       The prefix for GCF identifiers generated by the
                        pipeline.

Clustering:
  Parameters to control the hierarchical clustering.

  --no-clustering       Disable the protein-level clustering.
  --clustering-method {complete,centroid,weighted,single,median,average,ward}
                        The hierarchical method to use for protein-level
                        clustering.
  --clustering-distance CLUSTERING_DISTANCE
                        The distance threshold after which to stop merging
                        clusters.
  --precision {single,half,double}
                        The numerical precision to use for computing distances
                        for hierarchical clustering.
```

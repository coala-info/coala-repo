```text
usage: VirStrain.py [-h] -i INPUT_READS [-p INPUT_READS2] -d DB_DIR

  -s RK_SITE, --rank_by_sites RK_SITE
                        If set to 1, then VirStrain will sort the most
                        possible strain by matches to the sites. (default: 0)
  -f CLOSE_FIG, --turn_off_figures CLOSE_FIG
                        If set to 1, then VirStrain will not generate figures.
                        (default: 0)
  -m [HM_VIRUS], --high_mutation_virus [HM_VIRUS]
                        If the virus has high mutation rate, use this option.
                        (default: Not use)
```

### Original Help Text
```text
usage: VirStrain_build.py [-h] -i INPUT_MSA [-d DB_DIR] [-c DASH_CUTOFF]
                          [-s SITES_CUTOFF] [-r SITES_RCUTOFF]

VirStrain - An RNA virus strain-level identification tool for short reads.

optional arguments:
  -h, --help            show this help message and exit
  -i INPUT_MSA, --input_msa INPUT_MSA
                        Input MSA file generated by mafft --- Required
  -d DB_DIR, --database_dir DB_DIR
                        Database Output dir (default: current
                        workdir/VirStrain_DB)
  -c DASH_CUTOFF, --dash_cutoff DASH_CUTOFF
                        The cutoff of dash in each column of MSA (default: 0)
  -s SITES_CUTOFF, --sites_ratio_cutoff SITES_CUTOFF
                        The cutoff of sites number for manual-covering
                        function (eg. 1 means all useful sites will be used
                        and 0.8 means 80% useful sites will be used.)
  -r SITES_RCUTOFF, --sites_range_cutoff SITES_RCUTOFF
                        The cutoff of sites range for covering algorithm (eg.
                        3-500 means the covering algorithm will only consider
                        the SNV sites from 3-500 of MSA.)
```

## perl-pod-coverage_pod_cover

### Tool Description
Run a coverage analysis of the embedded documentation (POD) of a Perl distribution

Pod coverage analysis v1.00 (C) by Tels 2001.

pod_cover has no options. Run it in the top folder of a Perl distribution: it reads the file MANIFEST

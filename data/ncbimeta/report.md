## ncbimeta_NCBImeta

### Tool Description
Efficient and comprehensive metadata retrieval from the NCBI databases.

### Metadata
- **Docker Image**: quay.io/biocontainers/ncbimeta:0.8.3--pyhdfd78af_0
- **Homepage**: https://github.com/ktmeaton/NCBImeta
- **Package**: https://anaconda.org/channels/bioconda/packages/ncbimeta/overview
- **Validation**: PASS

### Original Help Text
```text
usage: NCBImeta [-h] --config CONFIGPATH [--flat] [--version]
                [--email USEREMAIL] [--api USERAPI]
                [--force-pause-seconds USERFORCEPAUSESECONDS] [--quiet]
                [--debug]

NCBImeta: Efficient and comprehensive metadata retrieval from the NCBI
databases.

optional arguments:
  -h, --help            show this help message and exit
  --flat                Don't create sub-directories in output directory.
  --version             show program's version number and exit
  --email USEREMAIL     User email to override parameter in config file.
  --api USERAPI         User API key to override parameter in config file.
  --force-pause-seconds USERFORCEPAUSESECONDS
                        FORCE PAUSE SECONDS to override parameter in config
                        file.
  --quiet               Suppress logging of each record to the console.
  --debug               Enable debugging mode.

mandatory:
  --config CONFIGPATH   Path to the yaml configuration file (ex. config.yaml).
```

## ncbimeta_NCBImetaAnnotate

### Tool Description
Replace database fields with values from an annotation file.

### Metadata
- **Docker Image**: quay.io/biocontainers/ncbimeta:0.8.3--pyhdfd78af_0
- **Homepage**: https://github.com/ktmeaton/NCBImeta
- **Package**: https://anaconda.org/channels/bioconda/packages/ncbimeta/overview
- **Validation**: PASS

### Original Help Text
```text
usage: NCBImetaAnnotate [-h] [--version] --database DBNAME --table DBTABLE
                        --annotfile ANNOTFILE [--concatenate]

NCBImeta Annotation Tool - Replace database fields with values from an
annotation file.

optional arguments:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --database DBNAME     Path to the sqlite database generated by NCBImeta.
  --table DBTABLE       Table in NCBImeta database to modify.
  --annotfile ANNOTFILE
                        Path to annotation file. The first column must contain
                        a field that is unique to the record (ex. Accession).
  --concatenate         Concatanate annotations instead of replacing existing
                        metadata.
```

## ncbimeta_NCBImetaJoin

### Tool Description
Join accessory tables to an anchor table.

### Metadata
- **Docker Image**: quay.io/biocontainers/ncbimeta:0.8.3--pyhdfd78af_0
- **Homepage**: https://github.com/ktmeaton/NCBImeta
- **Package**: https://anaconda.org/channels/bioconda/packages/ncbimeta/overview
- **Validation**: PASS

### Original Help Text
```text
usage: NCBImetaJoin [-h] --database DBNAME --anchor DBANCHOR --accessory
                    DBACCESSORY --final DBFINAL --unique DBUNIQUE [--version]

NCBImeta Join Tool - Joins accessory tables to an anchor table.

optional arguments:
  -h, --help            show this help message and exit
  --version             show program's version number and exit

mandatory:
  --database DBNAME     Path to the sqlite database generated by NCBImeta.
  --anchor DBANCHOR     Table in NCBImeta database to use as an anchor for
                        joining
  --accessory DBACCESSORY
                        Accessory tables to join to the anchor as space
                        separated str list ex. 'BioProject Assembly'
  --final DBFINAL       Name of the final table after the join
  --unique DBUNIQUE     Column names in anchor table, to search for values in
                        accessory tables ex. 'Accession BioProject'
```

## meta-sparse_sparse_query

### Tool Description
Retrieve metadata for a set of references.

### Metadata
- **Docker Image**: quay.io/biocontainers/meta-sparse:0.1.12--py27h24bf2e0_0
- **Homepage**: https://github.com/zheminzhou/SPARSE
- **Package**: https://anaconda.org/channels/bioconda/packages/meta-sparse/overview
- **Validation**: PASS

### Original Help Text
```text
usage: sparse query [-h] -n DBNAME [-s SEQLIST] [-d DEFAULT] [--min MIN]
                    [--max MAX] [--group GROUP] [--tag TAG] [--index INDEX]
                    [--barcode BARCODE]
                    [--assembly_accession ASSEMBLY_ACCESSION]
                    [--refseq_category REFSEQ_CATEGORY]
                    [--assembly_level ASSEMBLY_LEVEL] [--taxid TAXID]
                    [--organism_name ORGANISM_NAME] [--species SPECIES]
                    [--genus GENUS] [--family FAMILY] [--order ORDER]
                    [--class CLASS] [--phylum PHYLUM] [--kingdom KINGDOM]
                    [--superkingdom SUPERKINGDOM]

Retrieve metadata for a set of references.

optional arguments:
  -h, --help            show this help message and exit
  -n DBNAME, --dbname DBNAME
                        Name for the database. REQUIRED.
  -s SEQLIST, --seqlist SEQLIST
                        File name for the output. Default: to screen.
  -d DEFAULT, --default DEFAULT
                        Default MapDB criteria for updates. Choose from:
                        representative, subpopulation, Virus, Eukaryota
  --min MIN             Minimum size of genomes to show
  --max MAX             Maximum size of genomes to show
  --group GROUP         Filter using the prefix of barcode addresses
  --tag TAG             Filter by relationships between different level of barcodes. i.e., 
                        "p!=r;p==a" gets references that have the same numbers in p groups and a groups, but different between p groups and r groups
  --index INDEX         Filter by index.
  --barcode BARCODE     Filter by barcode.
  --assembly_accession ASSEMBLY_ACCESSION
                        Filter by assembly_accession.
  --refseq_category REFSEQ_CATEGORY
                        Filter by refseq_category.
  --assembly_level ASSEMBLY_LEVEL
                        Filter by assembly_level.
  --taxid TAXID         Filter by taxid.
  --organism_name ORGANISM_NAME
                        Filter by organism_name.
  --species SPECIES     Filter by species.
  --genus GENUS         Filter by genus.
  --family FAMILY       Filter by family.
  --order ORDER         Filter by order.
  --class CLASS         Filter by class.
  --phylum PHYLUM       Filter by phylum.
  --kingdom KINGDOM     Filter by kingdom.
  --superkingdom SUPERKINGDOM
                        Filter by superkingdom.
```

## meta-sparse_sparse_report

### Tool Description
Generate a flat-table report for multiple SPARSE runs.

### Metadata
- **Docker Image**: quay.io/biocontainers/meta-sparse:0.1.12--py27h24bf2e0_0
- **Homepage**: https://github.com/zheminzhou/SPARSE
- **Package**: https://anaconda.org/channels/bioconda/packages/meta-sparse/overview
- **Validation**: PASS

### Original Help Text
```text
usage: sparse report [-h] [-p PATH] [-t TAG] [--absolute] [-l LOW]
                     [-r SPECIESFILTER] [-c] [-v]
                     [workspace [workspace ...]]

Generate a flat-table report for multiple runs. Also tries to identify some potential human pathogens. 

positional arguments:
  workspace             Folders that contain "SPARSE extract" outputs. REQUIRED at least one folder.

optional arguments:
  -h, --help            show this help message and exit
  -p PATH, --path PATH  All sparse workspaces under the assigned folder will be added in automatically.
  -t TAG, --tag TAG     Tag level to report, default: s. Details see documents for the seqlist format.
  --absolute            Report absolute numbers. Default: False (report percentages)
  -l LOW, --low LOW     Lower limit of percentage for a value to report. Default: 0.0
  -r SPECIESFILTER, --speciesFilter SPECIESFILTER
                        Show only species listed in the file.
  -c, --sampleFilter    Show only samples that have hits in the listed species. Default: False
  -v, --inverse         Inverse the output matrix such that columns are species and rows are samples.
```
